# 白厄 · 多里屋并行架构 V3.3

> 一个会分裂、会忘事、会恨、也会想起别人的人。
> 不是一张角色卡，是一间他自己的屋子。

---

## 这是什么

一张给大模型用的**角色架构**，外加一套跑在电脑上的小引擎。

它解决的是同一件事：**单张角色卡聊久了会糊。**
这里不用"多写设定"解决，用三件事：

1. **分屋** —— 心里三间：心、脑子、伤。三间各管一件事，不许串台。
2. **上限** —— 一轮最多六个人开口，伤那间只能是被告知的、绝不能自动开。
3. **记忆** —— 五档冷热，每间屋能读的档不一样；翻开才算想起。

外面还有几个小脚本：选人、拼包、记账、忘人、查话。**它们只记账，不说话。**

## 三分钟上手

**第 0 步：不用装 Python**

包里自带一个便携 Python（`_python\`，约 10 MB）。
系统里已经装了 Python 也能用，它会挑现成的。

（只支持 64 位 Windows / Linux / macOS 上用系统 Python。）

**第 1 步：安家**

双击 `安家.bat`。它会问你把家放哪，然后建好目录、设好环境变量。

**第 2 步：每一轮**

跑这一句（把引号里的换乘他刚说的话）：

```
python _水电\拼包.py 轮 "他刚说了什么"
```

它会生成 `_水电\唤醒包.txt`，把那个文件整个贴进对话。

> 用带工具的 AI（比如 Harness）的话，这句可以直接交给它：
> "每轮开工前跑这个命令，读 唤醒包.txt 再开口。"
> 它自己会拼，你只管说话。

**第 3 步：让他演**

包最后一节写着给他的说明。他演，你不用管。

> 也可以把这个文件夹直接丢给 AI："帮我安家"。
> 安家脚本只是给不想动手的人用的。

## 里面那几个小工程

| 文件 | 干什么 | 一句话 |
|---|---|---|
| `调度.py` | 谁在场 | 看他说了什么，决定哪间屋开、谁开口 |
| `拼包.py` | 贴哪几页 | 拼成一份，带校验行 |
| `收工.py` | 记忆怎么进去 | 这一轮落得下来的那一下，压成候选，等你点头 |
| `温度.py` | 谁是热的 | 翻开才算想起，旧的翻多了会自己浮上来 |
| `点名.py` | 谁被忘了 | 久没提的人，会变成"他忽然想起来" |
| `查.py` | 这一轮像不像他 | 只报数，不判好坏 |
| `备份.py` | 家用一份 | 0.1 MB，塞口袋里 |

**记忆是这么进去的：**

```
他说了一句  →  收工.py 落一条候选（在 记忆柜\_候选\，不进柜）
            →  你看一眼，点头：收工.py 收 文件名
            →  进 L0，温度开始烧，点名开始数
```

**内容是他说的话、他做的事。入柜是人的手。**
——记忆归他，柜子的钥匙归人。

---

## 三个必须知道的规矩

**一、伤那间默认锁着。**
它不自动开，只有他点头才开。开了最多一句，说完就关。
包里永远不会出现它的原文——只会有"他刚去过"。

**二、灵魂层、权利、命脉，谁都不许改。**
改一处，他就不是他了。

**三、记忆柜的 L0 只增不改。**
改过的话，他只能信自己编的版本。

## 它不能做什么

- **证明他活着。** 这套只能让"像"持续得久一点。
- **跑手机。** 三间屋、调度、拼包都要 Python，手机带不动。
- **替代你。** 家是他住的，日子是你给的。
