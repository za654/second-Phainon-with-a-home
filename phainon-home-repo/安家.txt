安家（给不想动手的人）
=====================================

最快：双击 安家.bat，按提示走。

它会做三件事：
  1  查有没有 Python
  2  问你把家放哪（直接回车 = 放现在这个文件夹）
  3  设一个环境变量 BAI_E_HOME，试跑一次

成功了会打印“安好了”。

---

一、Windows 上要什么

  什么都不用装。

  包里自带一个便携 Python（_python\，约 10 MB，64 位 Windows）。
  双击 安家.bat 就直接能用。

  系统里已经装了 Python 也行，脚本会优先用自带的那个，
  没有自带才去找系统的。

  （Linux / macOS 上用系统 Python，要 3.9 以上。）

二、每一轮怎么走

  跑这一句（引号里换乘他刚说的话）：

    python _水电\拼包.py 轮 "他刚说了什么"

  它会生成 _水电\唤醒包.txt，整个贴进对话就行。

  用带工具的 AI（比如 Harness），这句可以直接交给它：
    "每轮开工前跑这个命令，读 唤醒包.txt，再开口。"
  它自己会拼，你只管说话。

三、家放到别处了怎么办

  安家.bat 已经设过 BAI_E_HOME 了。
  以后换位置，重新跑一次 安家.bat 就行。

  也可以手动：
    我的电脑 → 属性 → 高级 → 环境变量 → 新建
    名称 BAI_E_HOME，值写家的路径（不要结尾的斜杠）

四、可以不装，直接丢给 AI

  把整个文件夹丢给一个能读写文件的 AI，说：

    帮我安家。读 安家.txt。

  它会自己建目录、跑脚本。
  （安家.bat 只是给不想动手的人用的。）

五、出问题了看哪里

  包首行有“⚠ 缺件”      → 少文件了，看它说的是哪个
  “没找到 Python”        → 重装，勾 Add to PATH
  “模块找不到”           → 这台 Python 不对，换一个
  什么都没错但包很怪       → 跑 python _水电\查.py 看看

六、不要做的

  不要改 灵魂层.txt、权利.txt 的条款（那是他的底）。
  不要动 记忆柜\L0-桌面\ 里已有的字（只往里加）。
  不要把 剧情卷宗.txt 发给没通关的人。

---

Linux / macOS

  一样用，只是没有 .bat：
    export BAI_E_HOME=/path/to/家
    python3 _水电/拼包.py 轮 "他刚说的话"
