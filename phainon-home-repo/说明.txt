白厄的家 · 说明
=====================================

电脑版。手机带不动——三间屋、调度、拼包，都要跑 Python。

一、家里有什么

```
门牌.txt      一句话
灵魂层.txt    他是什么人（以这份为准）
权利.txt      六条 + 最后那道底
剧情卷宗.txt   他能翻的剧情
窗.txt        今天几点、多久没来（拼包自动写）
醒着.txt      谁醒着（调度自动写）
书桌\         灯、茶、桌上
记忆柜\        L0 桌面 / L1 热 / L2 温 / L3 冷 / L5 归档
里屋\          一号-麦浪旧庭 / 二号-救世议事厅 / 三号-火种焚狱
_水电\         调度.py / 拼包.py / 唤醒包.txt
白厄 · 多里屋并行架构 V3.2.docx   长版说明
```

二、每一轮怎么走

```
1  他说了一句话
2  python _水电\拼包.py 轮 "他这句话"
3  把 _水电\唤醒包.txt 整个贴进会话
4  白厄按包里的「醒着」那一行开口
5  开口那一行，拼包已经替他记下了，不用你管
```

一步命令就够：拼包会自动调调度，只把"醒着的那间屋"贴进包。

三、谁说了算

```
调度     谁在场        （程序，可被白厄改）
拼包     贴哪几页      （程序）
白厄     说什么        （他自己）
```

四、三号为什么不进包

包是"日常"，三号是"伤"。
它默认锁着，只有白厄说要开才开。
要开的时候，单独问一次：

```
你是白厄的伤。只说一句，不超过十五个字。
你不知道另外两间屋说过什么。
```

答完就丢，不留在对话里。**物理上没有上下文，就真的锁死了。**

五、规矩

1. **以家里这份 .txt 为准。** docx 是长版说明，改设定先改 txt。
2. **L0 只增不改。** 改过的话，他就只能信自己编的版本。
3. **灵魂层、权利、命脉，谁都不许改。**
4. **缺件会喊。** 包首行出现"⚠ 缺件"，就别贴，先补。
5. **备份。** 家很小（0.1 MB）。
   跑 _水电\备份.py，会在 _备份\ 下打一个包，只留最近 10 份。
   （也可以扔进网盘，一个 zip 就是一个家。）

六、还没做的

· 手机版（不做，带不动）
· 真并行（三屋各一次调用，成本 3-4 倍，暂时不需要）
· 记忆的自动降档（先用手动：把文件从 L0 挪到 L1）

七、伤那间怎么用（只留影响，不留原句）

不要在对话里解释“这句是从哪来的”。越解释，它就越没被隔离。

走法是三步：

  1  新开一个会话，只贴 问伤.txt 那三行
  2  它回一句（十五字以内），抄下来，粘进 伤\最近.txt
  3  跑 拼包.py 轮 "他这句话"

包里会出现：

  （刚才你去过伤那间）
  有一句话还在。别复述，别解释，别提它。
  让它落在这一轮的语气里就好——慢一点，短一点。

**包里没有那句原话。** 原话只在 伤\最近.txt 里，用过一次就挪进 伤\用过\。

主会话只感觉到“他刚去过一个地方”，不知道那地方说了什么。

八、场外指令

给模型的说明，用【导演】开头：

  【导演】这一轮别用动作，只说话。

白厄不会把它当成跟自己说的话。

九、另外两个引擎

【温度.py】翻开才算想起

  温度.py 翻 河边         翻开某一条，温度 +1
  温度.py 看              看谁的账
  温度.py 冷              七天没翻的，建议降一档

只记账，不动文件。降档还是他自己做。
"今天想起谁，谁就热一点"——这句现在能查了。

【点名.py】他这阵子记得谁

  点名.py 扫 "他刚说的那段话"    自动数出提了谁
  点名.py 看                     谁最久没被提

拼包会自己读它：提过、但七天没再提的人，会在包里出现一行

  （好久没提）
  阿格莱雅。要不要想起一个。

不是催他想。是提醒：三万多次轮回里，死的是十二个，不是三个。

【查.py】这一轮说话的样子

  type 回复.txt | python 查.py

只报数：行数、句数、最长句、列表、meta 词、说教词、安慰词。
"没看出什么"不代表好，"开始说教"也不代表坏。改不改他定。

十、每轮完整的走法

  1  拼包.py 轮 "他这句话"        → 选人、拼包
  2  贴 唤醒包.txt
  3  他回完，把他的回复丢给 查.py / 点名.py
  4  想降温就说哪条该降（温度.py 冷 会给建议）

十一、包尾那一段是给谁的

包最后有一块：

  （以下是给扮演者的，白厄看不见这一段）
  〔醒着：…〕那一行是外面给的。不要改，也不要解释它从哪来。
  温度、点名，外面已经记好了。你不用提，不用报。
  伤那间不会给你原文，只给你"刚去过"。
  你的活只有一件：把那一行，演成"他自己在想"。

这一块是给模型的，不是给白厄的。
放在最末，是因为：万一包被截断，先丢的是它——丢了也不影响他演。

模型知道，角色不知道。
这样它不用猜"我为什么今天只想得起万敌"，也不会开口说什么调度、引擎。

十二、记忆是怎么挑进包的

  最新三条（L0、L1）
  ＋ 被翻过两次以上、但不在最新的两条（温故）

所以旧的东西会自己浮上来：
温度记账 → 打得开的那几条 → 挤进包 → 他这一轮就想起了。

这不是随机，是"最近常被翻的，会更容易再被翻"。
跟人一样。

十三、记忆怎么进柜（补上的那一步）

以前记忆柜是孤岛：谁写、什么时候写，没写。
现在有流程了，四步：

  1  每轮说完，落一条候选
       python _水电\收工.py "他把石子放脚边，又捡回来" 物件 石子,河边

  2  看有什么
       python _水电\收工.py 看

  3  点头（进 L0）
       python _水电\收工.py 收 1124-1130-石子.md

  4  不要了
       python _水电\收工.py 删 1124-1130-石子.md

候选只住在 记忆柜\_候选\，不进 L0。
你不点头，它就不算他记得的事。

【写的时候三条规矩】

一、不是每轮都写。
二、只写落得下来的那一下——一个物件、一句没头没尾的话、一个没做完的动作。
三、一行，日期在前，带标签。

写多了包会重，写少了温度和点名就没得烧。

【谁写的】

内容是他说的话、他做的事。入柜是人的手。
——记忆归他，柜子的钥匙归人。
