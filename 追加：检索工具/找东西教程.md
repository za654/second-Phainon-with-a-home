# 找东西 · 家大了以后，怎么翻

> 这一页只讲一件事：家里东西多了，别把整个家塞进包。
> 跟着做，大约十分钟。做完你会有一个"她自己能去翻"的家。

---

## 0. 它解决什么

包是有长度的。

一开始家里只有几条记忆，全贴进去没问题。
等到记忆柜几十条、剧情卷宗几万字、里屋三间屋都有东西，**再全贴，就是让她在读档案**。

**这套东西做的事：把"翻"从包里拿出来，放进硬盘。**

```
包里只说：手边有几张纸
要找的时候：她自己说一句，你去翻，翻到的那条现场给她看
```

---

## 1. 放进去

把 `找.py` 放进家里的 `_水电\`，就完事。

```
白厄的家\
  _水电\
    找.py        ← 放这里
    词表.json    ← 可选，见第 5 节
```

**不用装任何东西。** 纯 Python 标准库，跟拼包、温度那些脚本一样跑：

```
python _水电\找.py 万敌
```

> 它会自己认家：`找.py` 住在 `<家>\_水电\`，往上两层就是家。
> **整个家搬到别的盘、别的文件夹，照样能用。**

---

## 2. 第一次找

先看家里现在有什么：

```
python _水电\找.py 目录
```

会列出：记忆、里屋、书桌、卷宗、散落各多少条。

然后随便找一个：

```
python _水电\找.py 万敌
python _水电\找.py 河边那颗石子
python _水电\找.py 耐热
```

出一条，带出处：

```
〔记忆〕记忆柜/L1-热\1120-万敌比耐热.md
  标签：万敌, 耐热, 战友
```

**找不到就说找不到**，不会硬凑一条给你：

```
家里没有对得上「……你说那个词」的东西。
```

> （这里故意不写具体词：写了，这条路查的就会是这一页本身。）

---

## 3. 三个动作

```
找 <词>       找一条出来看
取 <词>       找到就记一张纸条到手边，包里只说"手边有几张"
用 <序号>     现场翻纸条指向的原文
```

**为什么分两步：** 找是"看一眼"，取是"记着这件事"。**取过的才算她想起过。**

---

## 4. 手边一张纸

纸条上只写位置，不抄内容。

```
手边 8 张
  ↓ 满了，按分数挑最弱的退下去
抽屉（放两天，按现实日期）
  ↓ 过期
垃圾桶（只留最近 20 张）
  ↓
真没了
```

**纸条没了，不等于她忘了。** 原文一直在记忆柜、里屋、卷宗里，随时能再找一次。

几个动作：

```
python _水电\找.py 临时       看手边是哪几张
python _水电\找.py 留 1       钉住（最多两张，永不淘汰）
python _水电\找.py 扔 1       手动退到抽屉
python _水电\找.py 抽屉       看抽屉里有什么
python _水电\找.py 捡 1       捡回来
python _水电\找.py 垃圾桶     看倒掉的
```

**包里永远只有一行：**

```
（手边一张纸）
手边有 3 张纸（最近想起过的东西，记着位置）。想知道是哪几张，说一句就行。
```

一行，不管几张。**删纸条也不用改包。**

---

## 5. 词表：让"换个说法"也能找到

家里的说法跟字面常常对不上：她说"那次吵架"，记忆里写的是"门口站了很久"。

`词表.json` 就是干这个的（可选，不写也能用）：

```json
{
  "吵": ["门口", "没说话", "转身"],
  "耐热": ["万敌", "火", "站着不动"]
}
```

**它有两个来源：**

**一、你自己写**（上面那样，放 `_水电\词表.json`）

**二、从家里挖**（推荐）

```
python _水电\找.py 挖词       从他记得的事、写过的标签里，找"总一起出现的词"
python _水电\找.py 收词       看挖到了哪几组，不动
python _水电\找.py 收词 石子   只收这一组
```

挖出来长这样（括号里是同现的份数）：

```
石子   → 河边(9)、脚边(8)、克制(6)
万敌   → 耐热(11)、站着(7)、战友(6)
```

> 挖词只取"标签"和正文，**不会自动生效**。
> 先看候选，觉得对再收——**挖错了收进去，她会开始乱联想。**

---

## 6. 它不准怎么办

**先量，别猜。**

把 `评测.py` 放进家里（跟 `找.py` 同一个仓库里那份），然后：

```
python 评测.py <你的家目录>
```

它会跑一组"问什么 → 应该找到哪份"的题，给你两个数：

```
hit@1   第一条就是对的 —— 她伸手拿到的第一张纸
hit@3   前三里有一张对的 —— 她翻两下能翻到
```

**低于 70%，先查词表和分块，别去怪模型。** 这套本来就不依赖模型。

---

## 7. 卡住了怎么办

**找不到，但家里明明有**
先看 `目录` 里那一类是不是 0 条。是 0 条 = 那个文件夹没被认出来。
最稳的办法是把它放进 `记忆柜\`、`里屋\`、`书桌\`、`卷宗\` 之一；**放在别处也能被"散落"兜住**，只是排得靠后。

**太慢**
单次 0.5 秒左右是正常的。要是几秒，多半是它在等本地的向量模型——**没开模型它会自己退，不用管。**

**写不进去**
杀毒软件可能正好在扫。它会重试几次，还不行会明说：

```
！写不进去：…（手边）。这次的东西没存下来。
```

**想加自己的说法**
写进 `_水电\词表.json` 就行，下次检索生效。**不用改代码。**

---

## 8. 一条边界

```
它只读档案，不改档案。
它写的只有：手边、抽屉、垃圾桶、温度账本、词表候选
原文一个字都不动。
```

**检索结果永远不进包。** 包只说"有几张纸"——**这是整套东西里最要紧的一条。**

---

**最后一句话：这套不是让家变聪明，是让家别再被包挤死。**
